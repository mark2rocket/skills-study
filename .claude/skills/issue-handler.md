# 이슈 처리 워크플로우

이 스킬은 GitHub 이슈를 분석하고 처리하는 자동화 워크플로우를 제공합니다.

## 작업 내용

1. 이슈 내용 분석:
   - 버그 리포트
   - 기능 요청
   - 문서 개선
   - 질문
2. 이슈 유형에 따른 자동 처리:
   - 버그: 재현 단계 확인, 관련 코드 분석, 수정 제안
   - 기능: 요구사항 분석, 구현 계획 제시
   - 문서: 개선 사항 적용
3. 관련 코드 및 파일 검색
4. 해결 방안 제시 또는 직접 수정

## 버그 처리 프로세스

1. 재현 가능한지 확인
2. 에러 스택 트레이스 분석
3. 관련 코드 위치 파악
4. 근본 원인 분석
5. 수정 구현
6. 테스트 추가
7. PR 생성

## 기능 요청 프로세스

1. 요구사항 명확화
2. 기술적 실현 가능성 평가
3. 아키텍처 설계
4. 구현 계획 작성
5. 단계별 구현

## 사용 방법

현재 컨텍스트의 이슈:

```
/issue-handler
```

특정 이슈 번호:

```
/issue-handler #123
```

자동 수정 모드:

```
/issue-handler #123 --fix
```
