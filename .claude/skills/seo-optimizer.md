# SEO 최적화 도구

이 스킬은 콘텐츠의 SEO를 분석하고 최적화합니다.

## 작업 내용

1. 키워드 리서치:
   - 메인 키워드 식별
   - 관련 키워드 제안
   - 롱테일 키워드 발굴
   - 키워드 난이도 평가
   - 검색 의도 분석

2. 온페이지 SEO 분석:
   - 제목 태그 (Title Tag) 최적화
   - 메타 디스크립션 작성
   - 헤딩 태그 (H1, H2, H3) 구조
   - URL 구조 최적화
   - 이미지 Alt 텍스트
   - 내부 링크 전략

3. 콘텐츠 최적화:
   - 키워드 밀도 체크
   - 콘텐츠 길이 추천
   - 가독성 점수
   - 의미론적 키워드 추가
   - Featured Snippet 최적화

4. 기술적 SEO:
   - 페이지 속도 체크리스트
   - 모바일 친화성
   - 구조화된 데이터 (Schema Markup)
   - 캐노니컬 태그

5. 경쟁사 분석:
   - 상위 랭킹 페이지 분석
   - 키워드 갭 분석
   - 백링크 기회 탐색

## 출력 형식

```markdown
## SEO 분석 리포트

### 📊 종합 점수: [점수]/100

### 🎯 타겟 키워드
- 메인 키워드: [키워드]
- 관련 키워드: [키워드 리스트]
- 롱테일 키워드: [키워드 리스트]

### ✅ 잘된 점
- [항목 1]
- [항목 2]

### ⚠️ 개선 필요
- [문제점] → [해결 방안]
- [문제점] → [해결 방안]

### 📝 최적화 제안

#### 제목 태그
**현재:** [현재 제목]
**추천:** [최적화된 제목]

#### 메타 디스크립션
**현재:** [현재 설명]
**추천:** [최적화된 설명]

#### 콘텐츠 구조
[구조 개선 제안]

### 🔗 링크 전략
- 내부 링크: [제안]
- 외부 링크: [제안]

### 📈 예상 효과
[최적화 후 예상되는 개선 사항]
```

## 사용 방법

URL 분석:
```
/seo-optimizer
"https://example.com/blog-post를 분석해줘"
```

콘텐츠 최적화:
```
/seo-optimizer
"이 블로그 포스트를 SEO 최적화해줘"
[콘텐츠 내용 붙여넣기]
```

키워드 리서치:
```
/seo-optimizer --keyword-research
"'디지털 마케팅' 키워드 리서치해줘"
```

경쟁사 분석:
```
/seo-optimizer --competitor-analysis
"'클라우드 서비스' 키워드로 상위 랭킹 페이지 분석해줘"
```

## SEO 체크리스트

### 필수 항목
- [ ] 타겟 키워드가 제목에 포함되어 있는가?
- [ ] 메타 디스크립션이 150-160자 이내인가?
- [ ] H1 태그가 하나만 있는가?
- [ ] 이미지에 Alt 텍스트가 있는가?
- [ ] 내부 링크가 적절히 포함되어 있는가?
- [ ] 콘텐츠 길이가 최소 300단어 이상인가?
- [ ] 모바일 친화적인가?
- [ ] 페이지 로딩 속도가 3초 이내인가?

### 고급 최적화
- [ ] 구조화된 데이터 마크업
- [ ] Featured Snippet 타겟팅
- [ ] 관련 키워드 자연스럽게 포함
- [ ] E-A-T (전문성, 권위성, 신뢰성) 강화
- [ ] 사용자 경험 최적화

## 키워드 최적화 팁

1. **자연스러운 배치**: 키워드를 억지로 넣지 말고 자연스럽게
2. **동의어 활용**: LSI 키워드와 동의어 사용
3. **의도 매칭**: 검색 의도에 맞는 콘텐츠 제공
4. **롱테일 타겟팅**: 경쟁이 낮은 롱테일 키워드 공략
5. **지속적 모니터링**: 정기적인 순위 체크 및 업데이트
