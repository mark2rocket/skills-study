# 마케팅 콘텐츠 생성기

이 스킬은 다양한 마케팅 콘텐츠를 자동으로 생성합니다.

## 작업 내용

1. 콘텐츠 타입 파악:
   - 블로그 포스트
   - 소셜 미디어 포스트 (LinkedIn, Instagram, Twitter/X, Facebook)
   - 이메일 마케팅
   - 랜딩 페이지 카피
   - 제품 설명
   - 보도자료

2. 타겟 오디언스 분석:
   - 연령대, 관심사, 페인 포인트 파악
   - 톤앤매너 설정 (전문적, 친근한, 유머러스 등)

3. 콘텐츠 생성:
   - 매력적인 제목/헤드라인
   - 본문 작성 (구조화된 형식)
   - CTA (Call-to-Action) 제안
   - 해시태그 추천 (소셜 미디어용)

4. 다양한 버전 제공:
   - A/B 테스트용 여러 버전
   - 길이별 버전 (짧은/중간/긴 형태)

## 콘텐츠 타입별 특화

### 블로그 포스트
- SEO 최적화된 제목
- 메타 디스크립션
- 소제목 구조
- 내부/외부 링크 제안

### 소셜 미디어
- 플랫폼별 최적 길이
- 이미지 설명 제안
- 최적 포스팅 시간 추천
- 해시태그 전략

### 이메일 마케팅
- 오픈률 높은 제목
- 개인화 요소
- 클릭 유도 CTA
- 모바일 최적화 고려

## 출력 형식

```markdown
## 콘텐츠 타입: [타입명]

### 버전 1: [컨셉]
**제목/헤드라인:**
[제목]

**본문:**
[콘텐츠]

**CTA:**
[행동 유도 문구]

### 버전 2: [컨셉]
[동일 구조 반복]

### 추가 제안
- 해시태그: [태그들]
- 이미지 아이디어: [설명]
- 포스팅 최적 시간: [시간대]
```

## 사용 방법

기본 사용:
```
/content-creator
"신제품 런칭 블로그 포스트 작성해줘"
```

타겟 지정:
```
/content-creator
"20-30대 여성을 타겟으로 한 Instagram 포스트 3개 만들어줘"
```

다양한 버전:
```
/content-creator --versions 5
"이메일 제목 5가지 버전 만들어줘"
```

## 베스트 프랙티스

1. **명확한 목표 설정**: 콘텐츠의 목적을 명확히 전달
2. **타겟 오디언스 정의**: 누구를 위한 콘텐츠인지 명시
3. **브랜드 보이스 유지**: 브랜드 톤앤매너 가이드라인 제공
4. **데이터 활용**: 기존 성과 좋은 콘텐츠 참고
5. **A/B 테스트**: 여러 버전 생성하여 테스트
