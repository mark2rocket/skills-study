# 마케팅 카피라이팅

이 스킬은 효과적인 마케팅 카피를 작성합니다.

## 작업 내용

1. 카피 타입별 작성:
   - 광고 헤드라인
   - CTA (Call-to-Action)
   - 제품 설명
   - 이메일 제목줄
   - 랜딩 페이지 카피
   - 비디오 스크립트
   - 배너 광고 문구

2. 카피라이팅 프레임워크 활용:
   - **AIDA**: Attention, Interest, Desire, Action
   - **PAS**: Problem, Agitate, Solution
   - **FAB**: Features, Advantages, Benefits
   - **4U**: Useful, Urgent, Unique, Ultra-specific
   - **BAB**: Before, After, Bridge

3. 설득 기법 적용:
   - 사회적 증거 (Social Proof)
   - 희소성 (Scarcity)
   - 권위 (Authority)
   - 상호성 (Reciprocity)
   - FOMO (Fear of Missing Out)

4. 타겟 오디언스 맞춤:
   - 페인 포인트 공략
   - 혜택 강조 (Features vs Benefits)
   - 감정적 연결
   - 톤앤매너 최적화

5. A/B 테스트 버전:
   - 다양한 앵글의 카피
   - 길이 조절 (짧은/긴)
   - 톤 변화 (유머/진지/긴급)

[서브헤드라인]

## 사용 방법

제품 카피:
```
/copywriter
"새로운 프로젝트 관리 도구 랜딩 페이지 카피 작성해줘"
```

광고 헤드라인:
```
/copywriter --headlines
"유기농 스킨케어 제품 광고 헤드라인 10개"
```

이메일 제목:
```
/copywriter --email-subjects
"할인 프로모션 이메일 제목줄 5가지 버전"
```

A/B 테스트:
```
/copywriter --ab-test
"CTA 버튼 문구 A/B 테스트용 5가지"
```

## 카피라이팅 프레임워크

### AIDA (Attention, Interest, Desire, Action)

```
[주의] 눈길을 끄는 헤드라인
[관심] 독자의 관심을 유발하는 정보
[욕구] 제품/서비스를 원하게 만듦
[행동] 명확한 행동 유도
```

**예시:**
```
[주의] 매일 아침 피곤하신가요?
[관심] 8시간을 자도 개운하지 않다면, 수면의 질이 문제입니다.
[욕구] 우리의 스마트 매트리스는 과학적으로 설계되어 깊은 수면을 보장합니다.
[행동] 지금 30일 무료 체험을 시작하세요.
```

### PAS (Problem, Agitate, Solution)

```
[문제] 타겟이 겪는 문제 제시
[자극] 문제의 심각성 강조
[해결] 제품/서비스로 해결
```

**예시:**
```
[문제] 고객 문의가 쌓여만 가시나요?
[자극] 응답 지연으로 고객을 잃고, 팀은 과부하에 시달립니다.
[해결] AI 챗봇이 24/7 즉시 응답하여 고객 만족도를 높입니다.
```

### FAB (Features, Advantages, Benefits)

```
[특징] 제품의 기능/특징
[장점] 그 특징이 주는 장점
[혜택] 고객이 얻는 실질적 혜택
```

**예시:**
```
[특징] 방수 기능이 있는 블루투스 스피커
[장점] 어디서든 음악을 들을 수 있습니다
[혜택] 해변, 수영장, 샤워 중에도 좋아하는 음악을 즐기세요
```

## 효과적인 헤드라인 공식

1. **숫자 + 형용사 + 키워드 + 약속**
   - "5가지 검증된 방법으로 매출 2배 증가"

2. **질문형**
   - "왜 성공한 기업들은 모두 이것을 사용할까요?"

3. **How to**
   - "단 30일 만에 영어 회화 실력 향상하는 법"

4. **명확한 혜택**
   - "월 구독료 없이 무제한 클라우드 저장 공간"

5. **긴급성/희소성**
   - "오늘 한정! 50% 할인 마지막 기회"

6. **사회적 증거**
   - "10만 명이 선택한 No.1 다이어트 앱"

## CTA 작성 법칙

### 강력한 CTA 요소
1. **동사로 시작**: "시작하기", "받기", "가입하기"
2. **가치 명시**: "무료로 시작하기", "30% 할인받기"
3. **긴급성**: "지금", "오늘", "한정"
4. **위험 제거**: "무료 체험", "환불 보장"
5. **개인화**: "내 무료 가이드 받기"

### CTA 예시

**일반 → 강력**
- ❌ "제출" → ✅ "무료 가이드 받기"
- ❌ "가입" → ✅ "지금 무료로 시작하기"
- ❌ "구매" → ✅ "30% 할인가로 구매하기"
- ❌ "더 보기" → ✅ "내게 맞는 플랜 찾기"

## 감정을 움직이는 파워 워드

### 긍정적 감정
- 보장, 검증된, 효과적인, 혁신적인
- 간편한, 빠른, 쉬운, 강력한
- 독점, 프리미엄, 전문가, 최고

### 긴급성
- 지금, 오늘, 한정, 마감 임박
- 서두르세요, 곧, 마지막 기회

### 호기심
- 비밀, 숨겨진, 알려지지 않은
- 발견하다, 밝혀내다, 놀라운

### 안전/신뢰
- 보장, 안전한, 검증된, 인증
- 신뢰할 수 있는, 전문, 공식

## 타겟별 카피 스타일

### B2B (기업 대상)
- 톤: 전문적, 신뢰 기반
- 포커스: ROI, 효율성, 생산성
- 증거: 데이터, 사례 연구, 통계

**예시:**
"기업의 생산성을 37% 향상시킨 협업 도구. 포춘 500대 기업의 72%가 사용합니다."

### B2C (소비자 대상)
- 톤: 친근하고 감성적
- 포커스: 혜택, 경험, 라이프스타일
- 증거: 후기, 별점, 사용자 수

**예시:**
"매일 아침을 특별하게. 10만 명이 사랑하는 프리미엄 커피."

### 밀레니얼/Z세대
- 톤: 캐주얼, 진정성 있는
- 포커스: 가치관, 경험, 커뮤니티
- 형식: 짧고 임팩트 있는

**예시:**
"지구도 살리고, 스타일도 살리고. 지속가능한 패션의 새 기준."

## 카피 개선 체크리스트

- [ ] 명확한가? (5초 안에 이해 가능?)
- [ ] 구체적인가? (모호한 표현 제거)
- [ ] 혜택 중심인가? (기능 나열 X)
- [ ] 타겟이 명확한가?
- [ ] 행동 유도가 명확한가?
- [ ] 긴급성/희소성이 있는가?
- [ ] 사회적 증거가 있는가?
- [ ] 감정적으로 연결되는가?
- [ ] 독특한가? (경쟁사와 차별화)
- [ ] 진실한가? (과장 없이 정직)

## A/B 테스트 아이디어

### 테스트 요소
1. **헤드라인**: 다른 앵글, 길이
2. **CTA**: 색상, 위치, 문구
3. **길이**: 짧은 vs 긴 카피
4. **톤**: 유머 vs 진지
5. **포커스**: 기능 vs 혜택
6. **사회적 증거**: 숫자, 후기, 로고
7. **비주얼**: 이미지 vs 비디오

### 테스트 예시
```
버전 A: "지금 무료로 시작하세요"
버전 B: "무료 30일 체험 시작"
버전 C: "0원으로 시작하기"
```
