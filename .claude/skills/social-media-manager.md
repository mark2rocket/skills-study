# 소셜 미디어 매니저

이 스킬은 소셜 미디어 콘텐츠 기획, 작성, 일정 관리를 도와줍니다.

## 작업 내용

1. 콘텐츠 캘린더 생성:
   - 주간/월간 포스팅 일정
   - 플랫폼별 최적 포스팅 시간
   - 콘텐츠 테마 및 시리즈 기획
   - 특별 이벤트/기념일 반영

2. 플랫폼별 콘텐츠 최적화:
   - **Instagram**: 이미지 중심, 해시태그 전략, 스토리/릴스
   - **LinkedIn**: 전문적 톤, 긴 형식, 업계 인사이트
   - **Twitter/X**: 짧고 임팩트 있는 메시지, 스레드
   - **Facebook**: 커뮤니티 참여, 다양한 형식
   - **TikTok**: 짧은 비디오, 트렌드 활용
   - **YouTube**: 긴 형식 비디오, SEO 최적화

3. 콘텐츠 타입 다양화:
   - 교육 콘텐츠 (How-to, 팁)
   - 엔터테인먼트 (밈, 유머)
   - 영감/동기부여
   - 제품/서비스 소개
   - 사용자 생성 콘텐츠 (UGC)
   - 비하인드 스토리
   - 설문/참여형 콘텐츠

4. 해시태그 전략:
   - 브랜드 해시태그
   - 트렌딩 해시태그
   - 니치 해시태그
   - 최적 해시태그 수량

5. 참여도 분석:
   - 최적 포스팅 시간 찾기
   - 콘텐츠 유형별 성과
   - 오디언스 반응 분석

## 사용 방법

월간 캘린더 생성:
```
/social-media-manager
"11월 소셜 미디어 콘텐츠 캘린더 만들어줘"
```

특정 플랫폼:
```
/social-media-manager --platform instagram
"Instagram 릴스 아이디어 5개 제안해줘"
```

캠페인 기획:
```
/social-media-manager --campaign
"신제품 런칭 소셜 미디어 캠페인 기획해줘"
```

해시태그 리서치:
```
/social-media-manager --hashtags
"피트니스 관련 최적 해시태그 30개 추천해줘"
```

## 플랫폼별 베스트 프랙티스

### Instagram
- 최적 포스팅: 주중 오전 11시, 오후 1-3시
- 해시태그: 10-30개 (믹스)
- 캡션: 2-3문장 + 이모지 활용
- 스토리: 하루 5-10개
- 릴스: 15-30초 (트렌드 활용)

### LinkedIn
- 최적 포스팅: 화-목 오전 8-10시
- 길이: 150-300단어 (긴 형식도 OK)
- 톤: 전문적이지만 접근 가능한
- 포맷: 줄바꿈으로 가독성 높이기
- 해시태그: 3-5개

### Twitter/X
- 최적 포스팅: 주중 오전 8-10시, 점심시간
- 길이: 100-280자
- 스레드 활용으로 스토리 전개
- 해시태그: 1-2개
- 트렌드 재빠르게 활용

### Facebook
- 최적 포스팅: 주중 오후 1-3시
- 긴 형식 콘텐츠도 가능
- 그룹 커뮤니티 활용
- 비디오 성과 우수
- 질문으로 참여 유도

### TikTok
- 최적 포스팅: 화-목 오후 6-10시
- 길이: 21-34초 (완주율 중요)
- 트렌드 사운드 활용
- 첫 3초가 결정적
- 해시태그: 3-5개

## 콘텐츠 믹스 전략 (80-20 규칙)

- 80%: 가치 제공 (교육, 영감, 엔터테인먼트)
- 20%: 프로모션 (제품, 서비스 홍보)

## 참여도 높이는 팁

1. **질문하기**: 댓글 유도
2. **스토리텔링**: 감정 연결
3. **비주얼 최적화**: 고품질 이미지/비디오
4. **일관성**: 정기적 포스팅
5. **트렌드 활용**: 빠른 대응
6. **UGC 활용**: 고객 콘텐츠 리포스트
7. **인터랙티브**: 투표, 퀴즈, Q&A
8. **적시성**: 실시간 이벤트 활용
