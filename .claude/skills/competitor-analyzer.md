# 경쟁사 분석 도구

이 스킬은 경쟁사를 분석하여 마케팅 전략 수립에 필요한 인사이트를 제공합니다.

## 작업 내용

1. 경쟁사 식별:
   - 직접 경쟁사 (동일 제품/서비스)
   - 간접 경쟁사 (대체재)
   - 신규 진입자
   - 시장 리더

2. 다차원 분석:
   - **제품/서비스**: 기능, 가격, 품질
   - **마케팅**: 메시지, 채널, 캠페인
   - **디지털 프레즌스**: 웹사이트, SEO, 소셜 미디어
   - **고객 경험**: UX, 서비스, 후기
   - **콘텐츠**: 블로그, 비디오, 리소스
   - **기술**: 사용하는 도구 및 플랫폼

3. SWOT 분석:
   - Strengths (강점)
   - Weaknesses (약점)
   - Opportunities (기회)
   - Threats (위협)

4. 벤치마킹:
   - 시장 점유율
   - 성장률
   - 브랜드 인지도
   - 고객 만족도

5. 차별화 전략:
   - 경쟁 우위 요소 발굴
   - 시장 공백 (White Space) 찾기
   - 포지셔닝 기회

## 사용 방법

전체 경쟁사 분석:
```
/competitor-analyzer
"프로젝트 관리 도구 시장의 주요 경쟁사 분석해줘"
```

특정 경쟁사:
```
/competitor-analyzer --company
"Asana의 마케팅 전략 분석해줘"
```

벤치마킹:
```
/competitor-analyzer --benchmark
"소셜 미디어 성과를 경쟁사와 비교해줘"
```

SWOT 분석:
```
/competitor-analyzer --swot
"경쟁사 3곳의 SWOT 분석해줘"
```

## 분석 프레임워크

### Porter's Five Forces (포터의 5가지 힘)

1. **신규 진입자의 위협**
   - 진입 장벽은?
   - 신규 경쟁자 가능성은?

2. **구매자의 협상력**
   - 고객 전환 비용은?
   - 가격 민감도는?

3. **공급자의 협상력**
   - 공급자 의존도는?
   - 대안은 있는가?

4. **대체재의 위협**
   - 어떤 대체재가 있는가?
   - 전환 가능성은?

5. **기존 경쟁자 간의 경쟁**
   - 시장 집중도는?
   - 차별화 수준은?

### 4P 분석

1. **Product (제품)**
   - 기능, 품질, 디자인
   - 차별화 요소

2. **Price (가격)**
   - 가격 전략
   - 할인/프로모션

3. **Place (유통)**
   - 판매 채널
   - 접근성

4. **Promotion (프로모션)**
   - 마케팅 메시지
   - 광고 채널
   - 콘텐츠 전략

## 차별화 전략 수립

### Blue Ocean 전략

경쟁이 없는 새로운 시장 창출:

1. **제거**: 업계 표준이지만 불필요한 것
2. **감소**: 과도한 요소
3. **증대**: 고객이 원하는 요소
4. **창조**: 업계에 없는 새로운 가치

### 포지셔닝 맵

2가지 축으로 시장 포지션 시각화:

```
        고가격
          |
프리미엄 브랜드 | 고급 기능
          |
----------+----------
          |
기본 기능 | 가성비 제품
          |
        저가격
```
