# 마케팅 분석 및 리포트

이 스킬은 마케팅 데이터를 분석하고 인사이트 기반 리포트를 생성합니다.

## 작업 내용

1. 데이터 수집 및 정리:
   - 웹사이트 트래픽 (GA4, 네이버 애널리틱스)
   - 소셜 미디어 지표
   - 이메일 마케팅 성과
   - 광고 캠페인 데이터
   - 전환율 및 ROI

2. 핵심 지표 (KPI) 분석:
   - **트래픽**: 방문자 수, 페이지뷰, 세션 시간
   - **참여도**: 이탈률, 클릭률, 댓글/공유
   - **전환**: 전환율, CPA, ROAS, LTV
   - **오디언스**: 인구통계, 관심사, 행동 패턴
   - **콘텐츠 성과**: 인기 페이지, 체류 시간

3. 트렌드 및 패턴 식별:
   - 계절성 분석
   - 성장/하락 트렌드
   - 이상치 탐지
   - 코호트 분석

4. 경쟁사 벤치마킹:
   - 시장 점유율
   - 소셜 미디어 성과 비교
   - 키워드 순위 비교

5. 액션 아이템 제시:
   - 개선 기회 식별
   - 우선순위 제안
   - 예산 최적화 방안

## 사용 방법

월간 리포트:
```
/marketing-analytics
"지난 달 마케팅 성과 리포트 작성해줘"
```

특정 채널 분석:
```
/marketing-analytics --channel social
"소셜 미디어 성과 분석해줘"
```

캠페인 분석:
```
/marketing-analytics --campaign
"블랙프라이데이 캠페인 성과 분석해줘"
```

경쟁사 비교:
```
/marketing-analytics --competitor
"경쟁사 대비 우리 성과 비교 분석해줘"
```

## 유용한 지표 정의

### 트래픽 지표
- **세션**: 사용자의 단일 방문
- **이탈률**: 한 페이지만 보고 떠난 비율
- **평균 세션 시간**: 방문당 평균 체류 시간
- **페이지/세션**: 세션당 평균 페이지뷰

### 참여도 지표
- **CTR (Click-Through Rate)**: 클릭률
- **Engagement Rate**: 참여율 (소셜 미디어)
- **Video Completion Rate**: 비디오 완주율
- **Scroll Depth**: 스크롤 깊이

### 전환 지표
- **CVR (Conversion Rate)**: 전환율
- **CPA (Cost Per Acquisition)**: 고객 획득 비용
- **ROAS (Return on Ad Spend)**: 광고 수익률
- **LTV (Lifetime Value)**: 고객 생애 가치
- **CAC (Customer Acquisition Cost)**: 고객 획득 비용

### 소셜 미디어 지표
- **Reach**: 도달한 고유 사용자 수
- **Impressions**: 총 노출 수
- **Engagement**: 좋아요, 댓글, 공유 합계
- **Follower Growth Rate**: 팔로워 증가율

## 인사이트 발굴 팁

1. **비교 분석**: 기간별, 채널별, 세그먼트별 비교
2. **패턴 찾기**: 요일별, 시간대별 패턴
3. **이상치 주목**: 급증/급감 원인 파악
4. **상관관계**: 여러 지표 간 관계 분석
5. **질문하기**: "왜?"를 계속 물어보기

## 리포트 작성 팁

1. **스토리텔링**: 데이터로 스토리 만들기
2. **시각화**: 그래프와 차트 적극 활용
3. **명확한 인사이트**: "그래서 뭐?"에 답하기
4. **액션 지향**: 실행 가능한 제안
5. **컨텍스트 제공**: 목표, 벤치마크, 시장 상황
