# 코드 리뷰 자동화

이 스킬은 코드 변경사항을 자동으로 리뷰하고 피드백을 제공합니다.

## 작업 내용

1. 현재 브랜치의 변경사항 확인 (git diff)
2. 다음 항목들을 중점적으로 검토:
   - 코드 품질 및 베스트 프랙티스
   - 잠재적인 버그나 에러
   - 성능 이슈
   - 보안 취약점 (SQL injection, XSS, 등)
   - 코드 중복
   - 테스트 커버리지
3. 구체적인 개선 제안 제공
4. 심각도별로 이슈 분류 (Critical, High, Medium, Low)

## 출력 형식

- **요약**: 전체 리뷰 요약
- **주요 발견사항**: 중요한 이슈들
- **개선 제안**: 파일별 구체적인 제안
- **긍정적인 점**: 잘 작성된 부분

## 사용 방법

```
/code-review
```

또는 특정 파일만:

```
/code-review src/specific-file.js
```
