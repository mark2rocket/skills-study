# 테스트 자동 실행 및 분석

이 스킬은 프로젝트의 테스트를 실행하고 결과를 분석합니다.

## 작업 내용

1. package.json에서 사용 가능한 테스트 명령어 확인
2. 테스트 실행:
   - 단위 테스트
   - 통합 테스트
   - E2E 테스트 (있는 경우)
3. 테스트 결과 분석:
   - 실패한 테스트 상세 분석
   - 커버리지 확인
   - 성능 메트릭
4. 실패 원인 파악 및 해결 방안 제시

## 자동 수정 옵션

테스트 실패 시 자동으로 수정을 시도할 수 있습니다:
- 명백한 문법 오류
- Import 누락
- 타입 오류

## 사용 방법

```
/test-runner
```

특정 테스트만 실행:

```
/test-runner --file src/__tests__/component.test.js
```

자동 수정 포함:

```
/test-runner --fix
```
