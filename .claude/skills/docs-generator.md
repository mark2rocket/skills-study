# 문서 자동 생성

이 스킬은 코드를 분석하여 자동으로 문서를 생성합니다.

## 작업 내용

1. 코드베이스 구조 분석
2. 다음 문서 자동 생성:
   - API 문서
   - 함수/클래스 문서
   - 사용 예시
   - 설치 가이드
   - 기여 가이드
3. JSDoc, TypeScript 타입, 주석 활용
4. 코드 예제 추출 및 검증

## 문서 타입

### API 문서
- 엔드포인트 목록
- 요청/응답 형식
- 인증 방법
- 에러 코드

### 컴포넌트 문서
- Props 설명
- 사용 예시
- 스타일링 옵션

### 개발자 가이드
- 프로젝트 구조
- 개발 환경 설정
- 코딩 컨벤션
- 테스트 작성 방법

## 사용 방법

전체 문서 생성:

```
/docs-generator
```

특정 파일/디렉토리:

```
/docs-generator src/api/
```

특정 타입:

```
/docs-generator --type api
/docs-generator --type components
```
